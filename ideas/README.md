# Ideas

The ideas backlog holds scoped project ideas and research topics. Builders use it to find something worth building. Maintainers use it to see what the community needs.

## How it works

1. Copy [_template.md](_template.md) to `ideas/<slug>.md`.
2. Fill in every field. Keep the idea scoped to something a small team can start within two weeks.
3. Open a pull request with the `track:ideas` label.
4. When someone claims an idea, set `status: claimed` and add their handle to `claimed_by`.
5. When it ships, set `status: shipped` and link the result.

## Status

| Status | Meaning |
| --- | --- |
| `open` | Available to claim |
| `claimed` | Someone is working on it |
| `shipped` | Built, with a link |

## Difficulty

| Level | Meaning |
| --- | --- |
| `starter` | A first-time builder can finish it |
| `intermediate` | Needs solid experience in one area |
| `advanced` | Needs depth in several areas |

## Quality bar

- The problem is real and you can name who has it.
- The idea is specific. "A better wallet" is not specific.
- Claims include a source or an example.
- You list the skills and kits that help a builder start.
