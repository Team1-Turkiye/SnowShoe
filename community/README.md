# Community

This folder holds material for people who organize, teach, and grow the builder community around SnowShoe.

## Contents

| Path | Purpose |
| --- | --- |
| [workshops/_template](workshops/_template/README.md) | Workshop kit template for events |
| [bounties](bounties/README.md) | Bounty program policy |

## How events feed the repository

1. Run a workshop from a workshop kit.
2. Collect the problems participants hit.
3. Open one issue per problem, labeled by track.
4. Fix skills and kits. Update the workshop kit.
5. Add the event results to the workshop kit's `results.md`.

## Contributing a workshop kit

Copy the template, fill in every section, and open a pull request with the `track:community` label. Reviewers check that a facilitator who was not at your event could run it.
