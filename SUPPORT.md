# Support

| You want to | Do this |
| --- | --- |
| Ask a question about using SnowShoe | Open a GitHub Discussion in the Q&A category |
| Report a bug | Open an issue with the bug template |
| Propose a skill, tool, kit, or idea | Open an issue with the matching template |
| Report a security problem | Follow [SECURITY.md](SECURITY.md) |
| Ask about contributing | Read [CONTRIBUTING.md](CONTRIBUTING.md), then comment on a `level:starter` issue |

Maintainers answer on a best-effort basis. Expect a first reply within 5 business days.
